# Age labels don't match the age the template is for

## Summary

Two "Music Band" templates meant for different ages both show the label "Ages 3–7", which isn't even an option in the Age Group filter.

## Description

### Steps to Reproduce

1. Log in as an admin and open the Templates page.
2. Search for "Music Band".
3. Look at the age info the server sends back for the two results.

### Actual Result

One Music Band is for ages 2–4 and the other for ages 4–8, but both are labelled "Ages 3–7". The filter only offers "Ages 2–4" and "Ages 4–8", so the label matches nothing.

### Expected Result

The label should match the template's actual age group and one of the filter options.
