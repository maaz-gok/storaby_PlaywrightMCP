# Pressing Escape doesn't close the popup

## Summary

After opening the "Delete this template?" popup, pressing Escape leaves it open.

## Description

### Steps to Reproduce

1. Log in as an admin and open the Templates page.
2. Click "Delete" on a template.
3. Press Escape.

### Actual Result

The popup stays open. It only closes if you first Tab to something behind the popup and then press Escape.

### Expected Result

Escape should close the popup no matter where focus is.
