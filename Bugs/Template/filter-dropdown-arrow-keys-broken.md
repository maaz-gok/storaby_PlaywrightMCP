# Arrow keys don't work in the filter dropdowns

## Summary

In the Age Group / Storefront section / Visibility dropdowns, the Arrow keys do not move through the options.

## Description

### Steps to Reproduce

1. Log in as an admin and open the Templates page.
2. Focus the "Age Group" button and press Enter to open the menu.
3. Press the Down arrow key.

### Actual Result

Nothing moves — focus stays on the "Age Group" button. The only way to reach an option is pressing Tab repeatedly.

### Expected Result

Arrow keys should move through the options ("All" → "Ages 2–4" → "Ages 4–8" and back), and the chosen option should be remembered.
